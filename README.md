
# DSA Problem Solutions

A collection of fundamental Data Structures and Algorithms
implemented in C++ for learning and coding interview preparation.

## Programs

- `searching.cpp` — Linear search
- `binary_search.cpp` — Binary search on a sorted array

## Concepts Covered

- Arrays
- Searching algorithms
- Loops and conditional statements
- Time complexity basics

## Complexity

| Algorithm | Best Case | Worst Case |
|---|---|---|
| Linear Search | O(1) | O(n) |
| Binary Search | O(1) | O(log n) |

## How to Run

Compile any program using a C++ compiler:

```bash
g++ searching.cpp -o searching
./searching
```

For binary search, replace `searching.cpp` with `binary_search.cpp`
and `searching` with `binary_search`.
